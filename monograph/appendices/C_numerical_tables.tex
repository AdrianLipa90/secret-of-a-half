\section{Interpretation rules}
The numerical and generated tables may be used to:
\begin{itemize}
  \item regression-test exact identities and candidate phase functions;
  \item compare detector-zero multiplicity;
  \item benchmark numerical precision;
  \item reproduce declared interval/certificate metadata;
  \item generate explanatory plots along the critical line.
\end{itemize}
They may not be used to infer RH from a finite sample, fit a construction to tabulated zeros and then call it canonical, or promote an OPEN universal inequality.

\section{Synthetic off-axis test points}
A robust algorithm should also be tested on synthetic entire functions with the same basic quartet symmetries as xi but with prescribed off-axis zero quartets. For a chosen $\rho\notin\Crit$, define
\[
F_\rho(s)=(s-\rho)(s-\bar\rho)(s-(1-\rho))(s-(1-\bar\rho)).
\]
Any construction that uses only abstract functional symmetry must survive this control. A candidate that uses arithmetic input must exhibit a principled, independently defined distinction. This synthetic fixture is therefore an anti-circularity test rather than evidence about the actual zeta zeros.
