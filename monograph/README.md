## Reproducible build

The authoritative build commands are in:

- `.github/workflows/build-and-test.yml`;
- `.github/workflows/vectorized-build-and-test.yml`.

Both workflows regenerate monograph assets before LaTeX compilation. The vector
workflow now also runs on pushes to `main`, so the post-merge monograph and the
parallel validation lanes are checked on the same repository state.

The build fails closed on:

- regression-test failures;
- claim-ledger or semantic-audit failures;
- missing generated figures;
- LaTeX errors;
- undefined citations/references;
- multiply defined references;
- overfull boxes detected by the CI grep gate.
