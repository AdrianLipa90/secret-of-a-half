\section{Interpretation rules}

The table may be used to:
\begin{itemize}
  \item regression-test candidate phase functions;
  \item compare detector-zero multiplicity;
  \item benchmark numerical precision;
  \item generate plots along the critical line.
\end{itemize}
It may not be used to infer the universal truth of RH or to fit a construction that is then described as canonical.

\section{Synthetic off-axis test points}

A robust algorithm should also be tested on synthetic entire functions with the same symmetries as xi but with prescribed off-axis zero quartets. For a chosen $\rho\notin\Crit$, define
\[
 F_\rho(s)=(s-\rho)(s-\bar\rho)(s-(1-\rho))(s-(1-\bar\rho)).
\]
Any state-construction procedure that uses only abstract functional symmetry should behave similarly on $F_\rho$ and therefore cannot distinguish RH. A candidate that uses arithmetic input should exhibit a principled difference. This synthetic control is an important anti-circularity test.
