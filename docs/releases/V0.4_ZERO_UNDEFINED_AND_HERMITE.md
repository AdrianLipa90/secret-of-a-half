# Version 0.4 integration note

This release candidate integrates two consecutive research steps:

1. PhaseNav–Weil Hermite Ladder v0.3 — an explicit countable dense-core programme replacing one isolated 2x2 profile by finite principal sections.
2. Zero–Undefined Reciprocal Duality v0.4 — a labelled-state geometry in which complement becomes `z -> 1/z`, with the half as reciprocal, spinor and Fisher–Rao self-dual point.

The exact algebra is separated from the exploratory ontology. IEEE NaN is only an implementation marker for `UNDEFINED_BOTTOM`; it is never used as a numeric value. The Riemann Hypothesis remains open.
